React Native Anime

Project untuk belajar React Native, sebuah aplikasi mobile katalog anime.
Tech Stack:
- React Native
- Typrescript
- Supabase
- Expo

API Anime:
- https://jikan.moe/

Fitur yang telah dibuat:
- Catalog Anime
- Keyword Search
- Genre Filter
- Registration & Login (dummy email)
- Anime List (guest & login)
- Anime Comment (guest & login)
